# Starting from a fresh clone

A clone is the source, not the lab. Five things are deliberately not in it. Four of them the
setup scripts rebuild; the fifth has to be supplied, and only on the full profile.

Skipping this and going straight to the build fails at `New-LabSeeds.ps1`, which complains it
cannot find a public key. That is confusing rather than informative.

## What a clone does not contain

| Missing | Why | How to get it |
| --- | --- | --- |
| `.lab-secrets/` | SSH key, console password and the seed images built from them. Never committed, in this repository or any other. | `setup\New-LabSecrets.ps1`, then the seed builders |
| The Ubuntu cloud image | 580 MB, published and hash-checked upstream. Fetching is cheaper than storing. | `setup\Get-LabImage.ps1` |
| `.cache/` | The Wazuh manager package is 508 MB. Fetched and hash-checked rather than stored. | `tests/fetch-engine-package.sh` |
| `scoring/data/`, `scoring/models/` | The AIT dataset and the weights trained from it. Rebuilt from their sources. | `scoring/import-ait.py`, then `train.py` |
| A Windows 11 ISO | Licensed installation media. Only the full profile needs one. | The free Windows 11 Enterprise evaluation image, from Microsoft |
| `evidence/` raw output | Live runs record account names, addresses and task contents. | Regenerated by running the scenarios |

## Also needed on the host

- Windows 10 21H2 or Windows 11, and an elevated PowerShell session for the steps that create
  VMs.
- A hypervisor: Hyper-V on Pro, Enterprise or Education, or VirtualBox 7.0 or later. Nothing
  here installs one. `setup\Test-LabHost.ps1` reports which are usable on this machine and
  prints the command for each.
- The Windows OpenSSH client, for `ssh`, `scp` and `ssh-keygen`. Windows 11 ships it.
- 60 GB free for the lean profile, 180 GB for the full one, plus about 8 GB transiently while
  the Ubuntu image is converted. `Test-LabHost.ps1` checks this against the profile.
- WSL with Ubuntu, only to run the offline rule suite.
- Python 3.10 or later with NumPy, only to rebuild the model. `scoring/requirements.txt`.

## Rebuilding the missing pieces

`setup\Test-LabHost.ps1` first, then steps 1 through 4 of [the build](setup.md). The short
version, from an elevated PowerShell at the repository root:

```
.\setup\Test-LabHost.ps1
.\setup\New-LabSecrets.ps1
.\setup\Get-LabImage.ps1
.\setup\New-LabSeeds.ps1
.\setup\New-WindowsSeed.ps1          # full profile only
```

`New-LabSecrets.ps1` will not overwrite an existing set without `-Force`, because replacing the
keypair locks out any VM already built against the old one.

For the offline rule suite, from a shell that can reach the internet:

```
wsl -d Ubuntu --exec bash tests/fetch-engine-package.sh
```

That downloads the Wazuh manager package and checks it against the SHA-256 published in the
signed apt index. A mismatch is deleted rather than kept, since a rule suite running against an
unverified engine proves nothing.

For the model, download `ait_ads.zip` and `labels.csv` from
[zenodo.org/records/8263181](https://zenodo.org/records/8263181) into `scoring/data/ait/`, then
from `scoring/`:

```
python import-ait.py                 # windows the alerts into episodes
python evaluate.py                   # eight folds, one per network. About fifty minutes
python evaluate_adaptive.py          # the baseline layer, measured the same way
python window-sensitivity.py         # what the window width and the split are worth
python export-model.py               # writes scorer/model.json
```

`export-model.py` refuses to write unless `score.py` and `features.py` compute the same
features from the same alerts, so a deployed model cannot quietly be fed different numbers
than it was fitted on.

## Then

[Build the lab](setup.md) from step 5. Once it is up, `Lab.cmd` at the root of the repository
opens the dashboard, which is where it is started and stopped day to day.

## Rebuilding on the same machine

The lab occupies a fixed address range, `172.29.70.0/24`, and `New-Lab.ps1` refuses to run if
a conflicting NAT already exists. Remove the old lab first:

```
.\setup\Remove-Lab.ps1
```

That leaves the virtual disks in place. `-DeleteDisks` removes those too.
